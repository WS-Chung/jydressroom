# 정연이의 딸기나라 (드레스룸) — 디자인 규칙

"하늘 친구들"(비행기 웹페이지, `../airplane`)에서 다듬은 디자인 규칙을 그대로 옮겨 온 문서입니다.
이 폴더는 하늘 친구들과 완전히 따로 움직이는 프로젝트이고, 이 문서가 디자인의 기준입니다.

- 대상: 만 5세 여자아이 **정연** (가족: 아빠, 엄마, 쌍둥이 남매 **정우**). 글을 막 읽기 시작한 나이, 혼자 터치로 놀아요
- 무엇: 딸기가 돈인 딸기나라에서 옷을 사고(쇼핑), 내 방에서 입고(옷 입히기), 나들이를 가는 놀이. 아이의 취향과 쓰는 습관을 어른이 기록으로 봐요
- 이름·가족은 `js/data/site.js`, 딸기 규칙과 옷 목록은 `js/data/items.js`, 나들이 장소는 `js/data/menus.js`

## 0. 놀이 순서와 딸기 규칙

| 단계 | 주소 | 하는 일 |
| --- | --- | --- |
| 처음 화면 | `#/` | 정연이 그림(긴 생머리, 하얀 원피스, 하얀 구두) + 말풍선 + "시작해요". 하던 놀이가 있으면 "이어서 해요 / 처음부터 해요" |
| 딸기나라 이야기 | `#/story` | 넘기기 6장: 딸기가 돈이에요 → 딸기 100개 → 보통 옷 10개·캐릭터 옷 20개 → 가족 선물도 있어요 → 바구니에 담아요 → 백화점으로 |
| 딸기 백화점 | `#/shop` | 옷을 누르면 거울 속 정연이가 입어 봐요(겹쳐 입기). 사고 싶으면 거울 아래 큰 "🧺 바구니에 담아요", 마음이 바뀌면 "✕ 빼요". 다 고르면 "🍓 계산해요" |
| 내 방 | `#/room` | 산 옷 + 처음 옷(하얀 원피스·구두)만 옷장에 있어요. 머리 모양 17가지(뿌까 머리·자두 머리 포함)·머리 색 6가지는 공짜 |
| 어디 갈까요? | `#/go` | 메뉴 카드 7장 (어린이집·여행·놀이터·키즈카페·밥 먹으러·생일 파티·놀이공원) |
| 나들이 | `#/go/<id>` | 그 장소 그림 위에 정연이(+ 선물 받은 가족)가 나오고 폭죽. "📸 사진 찍기"(사진이 우리 집 액자·냉장고에 붙어요), "처음으로". 여기서 놀이 끝 |
| 어른용 기록 | `#/parent` | 처음 화면에 링크 없음. 산 순서·가격·캐릭터 비율·가족 선물을 몇 번째 계산에서 샀는지·바구니에 담았다가 뺀 옷·많이 입어 본 옷·좋아한 색 |

- 처음 딸기 100개. 보통 옷 10개, 캐릭터 옷(마이멜로디·쿠로미·하츄핑) 20개, 가족 선물(아빠 회색 양복과 남색 넥타이·엄마 원피스·정우 로봇 점퍼) 10개
- **바구니(장바구니)로 사요**: 담기 → 계산해요 → 바구니 보기 → 정말 살까요? → 사요
  1. 바구니에 담으면 지갑의 "남은 딸기 🍓 ○"가 그만큼 줄어요. 남은 딸기 = 지금 쓸 수 있는 딸기 (가진 딸기 - 바구니 옷값). 빼면 다시 늘어요
     - 담은 옷 칸은 **회색으로 어둡게(비활성)** + "담았어요" 띠 + 🧺. 다시 누르면 입어 보기·담기는 안 되고, 칸이 고개를 젓듯 흔들리며 "🧺 이미 바구니에 담았어요 · 🧺 바구니 보기"
  2. **한 칸(원피스·윗옷·바지·치마·신발·모자)에서는 바구니에 3개까지만** 담아요 (`SHOP.maxPerCat`, 한 칸만 고르는 걸 막으려고). 3개를 담은 뒤 그 칸의 옷을 누르면 입어 보기는 되지만 "바구니에 담아요" 버튼 대신 "원피스는 이제 더 담을 수 없어요" + "다른 칸에서 골라 봐요"가 나와요 (조사는 칸 이름에 맞춰 원피스**는** · 윗옷**은** · 바지·치마**는** · 신발**은** · 모자**는**). 바구니에서 하나 빼면 다시 담을 수 있어요. 바구니에 있는 것만 세요 (이미 산 옷은 세지 않음). 선물 칸은 세 개뿐이라 해당 없음
  3. 쓸 수 있는 딸기보다 비싸면 담을 수 없어요: "딸기가 모자라요 😢" (+ 바구니가 차 있으면 "바구니에서 하나 빼 볼까요?")
  4. 옷 칸 오른쪽 아래 "🧺 바구니 보기 ③"(언제든 열어 봄) 또는 "🍓 계산해요" → 바구니 창: 옷 칸 구분 없이 담은 순서대로 옷 그림·이름·값, 한 줄마다 "✕ 빼요", "모두 🍓○". 버튼 "🍓 다 골랐어요" / "더 고를래요". 비어 있으면 "바구니가 비어 있어요." (계산해요로 열었을 때만 "🚪 내 방에 가요")
  5. "정말 살까요? 딸기 ○개를 내요." → "네, 살래요!" / "아니요"(→ 다시 바구니 보기)
  6. 사고 나면 되돌릴 수 없어요 (마음이 바뀌면 바구니에 있을 때 빼요)
- 가족 선물을 사면 선물 하나마다 딸기 10개를 받고 다시 백화점으로 돌아가요. 세 사람 모두면 "가족을 사랑하는 착한 어린이예요!" 칭찬과 함께 30개
  - 이 보상은 이야기에서 미리 알려 주지 않아요 (1번째 계산에서 산 선물 = 보상을 모르고 고른 선물)
  - 선물이 없는 계산이면 "다 샀어요! 내 방에 가서 입어 봐요." → "🚪 내 방에 가요" / "🏬 더 살래요"(딸기가 10개 이상 남았을 때)
  - 숫자는 `SHOP`(`js/data/items.js`) 한 곳에서 바꿔요. `allGiftsBonus`는 세 명 모두일 때 더 주는 딸기(지금 0)
- 원피스를 입으면 윗옷·바지·치마는 벗고, 윗옷이나 바지·치마를 입으면 원피스는 벗어요. 아무것도 안 입은 칸은 하얀 속옷이 보여요
- 놀이 상태와 기록은 그 기기의 localStorage(`berryland-now`, `berryland-history`, 최근 40번)에만 저장

## 1. 디자인 원칙

| 원칙 | 적용 방법 |
| --- | --- |
| 글자는 최소로 | 한 화면에 문장 1~2개. 숫자보다 그림·익숙한 것과 비교. 옷 칸에는 이름 없이 그림 + 🍓값만 (이름은 거울 아래에) |
| 쉬운 말 | 만 5세가 아는 낱말 ("상의" 대신 "윗옷", "하의" 대신 "바지·치마"). 어려운 말은 쉬운 말을 크게, 원래 단어는 작게 함께 |
| 맞춤법 | "~예요"(받침 없을 때: 비행기예요, 친구예요), "~이에요"(받침 있을 때), "~였어요" 붙여 쓰기. 이름은 받침에 따라 "정연이가·정연아 / 정우가·정우야" (`callName`·`vocative`) |
| 누르면 소리로 대답 | 버튼·카드·점·체크 상자를 누르면 짧은 "딸깍", 칭찬할 때는 폭죽 + 박수 소리. 바구니에 담을 때 "퐁", 살 때 "짤랑", 입어 볼 때 "뾰로롱", 딸기를 받을 때 높아지는 소리, 모자랄 때 낮은 "뿌웅", 사진 "찰칵". 소리 파일 없이 브라우저에서 바로 만듦. 읽어주기(TTS)는 없음 |
| 큰 손가락용 | 큰 버튼(최소 48px), 큰 카드, 좌우 넘기기(스와이프), 키보드 ← → |
| 흔들리지 않는 화면 | 넘기는 화면은 카드 높이를 가장 긴 장에 맞춰 고정 → ◀ ▶ 버튼 자리가 그대로 |
| 움직임 줄이기 존중 | 기기 설정이 '움직임 줄이기'면 모든 애니메이션을 끔 |

## 2. 해상도 · 화면 크기

- 빌드 없는 정적 사이트. `<meta name="viewport" content="width=device-width, initial-scale=1">`
- 기준 화면: 태블릿 가로 / 노트북. 세로 휴대폰도 깨지지 않게 반응형
- 확인하는 6가지 화면 크기: **390×844**(휴대폰 세로) · **844×390**(휴대폰 가로) · **768×1024**(태블릿 세로) · **1024×768**(태블릿 가로) · **1280×800**(노트북) · **1920×1080**(큰 모니터)
  - 어느 크기에서도 가로 스크롤(넘침)이 생기면 안 됨
- 나뉘는 폭
  - **760px 이하**: 휴대폰 모양 (위쪽 막대 72 → 62px, "처음부터 / 다시보기" 두 줄로 작게, 제목 20px, 버튼 조금 작게)
  - **900px 넘음**: 메뉴 카드 한 줄에 최대 4장
  - **900px 이하**: 메뉴 카드 한 줄에 2장
  - **520px 이하**: 메뉴 카드 한 줄에 1장
  - **480px 이하**: 옷 칸 위 탭 100px, 글자 14px ("바지·/치마"는 두 줄). 지갑은 "남은 딸기" 아래에 🍓 숫자
  - **세로 화면**: 처음 화면·백화점·내 방은 그림이 위, 버튼·옷 칸이 아래
  - **높이 520px 이하 가로**(휴대폰 가로): 백화점·내 방 거울 안을 "그림 | 지갑·버튼" 두 칸으로, 나들이는 "장면 | 글·버튼" 옆으로
  - **760px 이하 + 세로**: 필요한 화면에 "📱 휴대폰을 옆으로 돌리면 더 크게 보여요" 안내(`<p class="rotate-hint">`, 지금은 나들이 화면)
- 본문 바깥 여백: `12px clamp(12px, 3vw, 36px) 40px`. 내용 폭은 화면마다 최대값을 둠 (처음 화면 980px, 메뉴 1200px, 넘기기 화면 1000px, 백화점·내 방 1400px)
- 화면을 꽉 채워야 하는 화면(백화점·내 방)은 높이를 `100dvh - 위쪽 막대 - 여백`으로 잡고(아래 여백 14px), 옷 칸만 안에서 스크롤
- 나들이 장면은 `container-type: size` + `cqw/cqh`로 사람 크기를 정함 (사람 수가 많으면 작게, 혼자면 크게)
- 글씨 크기는 `clamp(최소, vw, 최대)`로 화면에 맞게 줄고 늘어남

### 무지개 테마 색 (메뉴마다 하나)

메뉴 카드 순서대로 **빨·주·노·초·파·남·보**. 카드 아래 10px 띠, 그 메뉴 안의 큰 버튼·점·넘기기 카드 윗줄 띠·작은 제목 글씨가 이 색.
지금 메뉴 카드는 "어디 갈까요?"의 나들이 장소 7곳이고, 그 밖의 화면은 이야기 = 빨강, 내 방 = 보라를 씀.

| 순서 | 이름 | 색 | 그 색 위 글씨(`-ink`) | 흰 바탕 위 글씨(`-text`) |
| --- | --- | --- | --- | --- |
| 1 | `red` 빨강 | #e53935 | 흰색 | 같은 색 |
| 2 | `orange` 주황 | #fb8c00 | 흰색 | 같은 색 |
| 3 | `yellow` 노랑 | #fdd835 | #23324a (진한 남색) | #a17c00 |
| 4 | `green` 초록 | #43a047 | 흰색 | 같은 색 |
| 5 | `blue` 파랑 (하늘색에 가까운 옅은 파랑) | #64b5f6 | #23324a | #1e78c8 |
| 6 | `navy` 남색 | #283593 | 흰색 | 같은 색 |
| 7 | `purple` 보라 | #8e24aa | 흰색 | 같은 색 |

- JS에서 `style="${theme('yellow')}"`처럼 이름으로 고르면 `--accent`·`--accent-ink`·`--accent-text`가 한꺼번에 정해짐. 화면 안의 버튼·점은 이 세 값만 씀 (`theme('pink')`도 됨)
- 노랑·옅은 파랑처럼 밝은 색 위에는 흰 글씨 대신 진한 남색 글씨 (잘 보이게)
- 색을 바꾸려면 `css/style.css`의 `--c-…` 한 곳만 고치면 됨
- 가격표: 보통 옷 분홍 바탕(#ffe4ef), 캐릭터 옷 금색 바탕(#fff1c2) + 칸 테두리 금색(#ffd54f) + ⭐

## 5. 화면 틀과 부품

- **위쪽 막대**: 화면 위에 붙어 있음(높이 72px, 휴대폰 62px), 흰색 85% + 살짝 흐림. 왼쪽 "🏠 처음부터 다시보기" 버튼, 가운데 화면 제목, 오른쪽은 같은 폭의 빈 자리(제목이 정가운데 오게)
- **처음 화면**: 큰 제목 + 정연이 그림(둥실둥실, 눈 깜빡) + 말풍선 + 큰 버튼. 가로 화면은 그림 왼쪽·말풍선 오른쪽, 세로 화면은 위아래. 주위에 🍓💖✨가 살랑살랑
  - 사진 출처 같은 어른용 링크와 어른용 기록 링크는 처음 화면에 두지 않음 (주소로만 열리게)
- **메뉴 카드** ("어디 갈까요?"): 흰 카드, 모서리 26px, 아래 10px 테마 색 띠, 큰 그림(그림 글자 92px) + 제목 + 작은 글씨. 줄마다 **가운데 정렬**, 넓은 화면 한 줄 최대 4장(7장이면 4 + 3), 카드 한 장 최대 285px. 올리면 살짝 위로, 누르면 살짝 작아짐
- **넘기기 화면** (딸기나라 이야기, 디자인 견본): 흰 카드 + 윗줄 12px 테마 색 띠 + 작은 제목(테마 글씨 색) + 동그란 그림(살랑살랑) + 제목 + 한두 문장. 아래에 ◀(72px 동그라미) · 점 · ▶
  - 점은 "1 / 20" 같은 숫자 대신 씀. 지금 장은 테마 색으로 크게, 점을 누르면 그 장으로
  - 처음 장에서는 ◀, 마지막 장에서는 ▶가 흐려짐
  - 카드 높이를 가장 긴 장에 맞춰 고정 (`lockHeight`, 화면·칸 크기가 바뀌면 다시 잼)
- **거울 + 옷 칸** (백화점·내 방, `.studio`): 왼쪽 거울(`.stage`) + 오른쪽 옷 칸(`.shelf`)
  - 거울: 백화점은 분홍 줄무늬 커튼 탈의실(`.fitting`), 내 방은 보라 줄무늬 벽지 + 나무 바닥(`.myroom`). 위에 딸기 지갑 "남은 딸기 🍓 ○"(`.wallet`, 바뀌면 통통 + "-10 🍓"가 떠오름), 아래(`.pick`, 백화점은 128px)에 옷 이름·값 글자 없이 상태만: 위아래로 큰 분홍 버튼 "🧺 바구니에 담아요"(`.cart-in-btn`, 높이 108px, 숨 쉬듯 1.06배로 커졌다 작아지기 `breathe` 1.8초 + 빛이 스치는 `glint` + 둘레 ✨ 4개 `twinkle`) / "🧺 바구니에 담았어요 · ✕ 빼요" / "✔ 샀어요" / "💝 선물했어요" / "원피스는 이제 더 담을 수 없어요"(한 칸 3개를 채웠을 때) / "딸기가 모자라요 😢". (내 방은 거울 아래에 고른 옷 이름이 나와요)
  - 가족 선물을 누르면 거울에 그 가족이 선물 옷을 입은 모습 + 이름표
  - 옷 칸: 위에 큰 탭(`.tabs` + `.tab`, 높이 112px · 휴대폰 가로 78px · 480px 이하 100px, 그림 40px 위 + 글자 아래, 고른 탭만 테마 색)
    - **선물 탭**(`.tab-gift`): 선물 상자처럼 금색 바탕 + 빨간 리본이 **세로·가로로 열십자** + 위에 🎀. 금빛이 은은하게 번지고(`gift-glow`), 비스듬한 흰 광택이 계속 훑고 지나가고(`gift-shine`, `::before`), 모서리의 ✦ 3개가 깜빡이고(`twinkle`), 🎁가 가끔 흔들흔들(`gift-wiggle`). '바구니에 담아요'(커졌다 작아지기·반짝이)와 다른 움직임
    - 탭과 그림 칸 사이 꾸밈선(`.shelf-divider`): 분홍 땡땡이 줄 + 아래로 늘어진 레이스 + 가운데 "🍓 🎀 🍓"
  - 그 아래 그림 칸(`.item-card`, 고른 칸은 테마 색 테두리, 바구니에 담은 칸은 회색 바탕 #e4e0e6 + 흑백으로 흐린 그림 + "담았어요" 띠 + 🧺(`.in-cart`, `aria-disabled`), 산 칸은 초록 ✔, 선물한 칸은 💝), 오른쪽 아래에 떠 있는 버튼(백화점 `.shelf-actions`: 흰 "🧺 바구니 보기 ③"(`.cart-btn`, 분홍 동그라미에 담은 개수, 0이면 회색, 480px 이하 "🧺 바구니 ③") + 분홍 "🍓 계산해요" / 내 방 `.done-btn` "🚪 다 입었어요!")
  - 바구니 보기 창(`.cart-box`): 한 줄(`.cart-row`)마다 옷 그림 + 이름 + 🍓값 + "✕ 빼요", 아래 "모두 🍓○", 담은 옷이 많으면 목록만 안에서 스크롤 (휴대폰 가로에서도 버튼이 화면 안에)
  - 내 방 "머리" 탭: 머리 색 동그라미 6개(`.color-dot`) + 머리 모양 17칸
- **나들이 장면** (`.scene`): 흰 테두리 6px의 둥근 장면. 가로 16:10, 세로 1:1. 배경은 SVG(`js/scenes.js`, 가운데에 사람이 서도록 꾸밈은 양옆), 사람은 아래 가운데(아빠 · 정연 · 정우 · 엄마 순서, 선물 받은 가족만). 정연이는 콩콩 뛰고, 사진 찍기를 누르면 번쩍
  - **사진 → 우리 집에 붙이기** (`.photo-wall` 창): 찰칵 → 가운데에 폴라로이드 사진이 나와서 하얗다가 천천히 보이고(`develop` 1.3초) → 1.5초 뒤 제자리로 날아가 붙어요(`퐁`). 첫 사진은 벽에 끈으로 건 **금색 액자**(`.pw-frame`), 그다음부터는 **냉장고**(`.fridge`, 자리 6개)에 자석(🍓🌸⭐💖🍒🌈)으로 비스듬히. 사진 아래 글씨는 장소 그림 + "10월 31일"
  - 사진 속 장면은 나들이 장면을 그대로 다시 그리고 움직임만 멈춰요(`.scene.snap`). 사진 목록은 `G.photoList` [{ place, t }] (최대 31장, 넘치면 가장 옛 냉장고 사진부터)
  - 창 글: "🖼️ 액자에 넣었어요! / 벽에 예쁘게 걸어 두었어요." · "🧲 냉장고에 붙였어요! / 냉장고에 사진이 ○장 있어요." 버튼 "좋아요!" / "📸 또 찍을래요"
  - 키 비율: 아빠 180 · 엄마 160 · 정우 120 · 정연 110 (cm, `js/data/site.js`의 `childHeight`·`family.*.height`). 머리 꼭대기~발바닥 길이를 이 비율로 맞추고 발은 같은 땅에. 가장 큰 사람이 장면 높이의 74%(혼자면 64%), 모두 폭 안에 들어오게 1cm 길이(`--u`)를 정해요
- **버튼**: 큰 버튼(테마 색, 알약 모양), 흰 큰 버튼(`.big-btn.alt`), 작은 버튼(흰색), 그림 버튼(56px), 두세 가지 중 고르기(`.modes` + `.mode-btn`, 고른 것만 테마 색), 켜고 끄기(`.toggle`), 이름표(`.chip`, `.chip.hot`), "처음으로" 링크(`.back-link`)
- **창(모달)**: 어두운 막 + 흰 창 + 금색 동그란 메달(빙글 돌며 나타남) + (가족 얼굴) + 제목 + 한 줄 + 버튼 1~2개(첫 버튼은 테마 색, 둘째는 흰색). 칭찬할 때는 폭죽(🎉✨⭐🎈💖🌈, 선물 칭찬은 🍓💖🎁✨)이 위에서 떨어지고 박수 소리. 묻는 창: "쇼핑을 다 했어요?", "처음부터 할까요?"
- **움직임**: 나타날 때 살짝 커지며(pop 0.35초), 그림은 살랑살랑(bob 2.6초), 구름은 70~120초에 한 번 지나감, 정연이 눈은 5초마다 깜빡, 옷을 입으면 ✨💖⭐ 반짝, 나들이 배경은 그네·관람차·비행기가 천천히 움직임

## 5-1. 그림 (그림 파일 없이 SVG)

- 사람·옷·머리·모자는 모두 `js/doll.js`가 SVG로 바로 그려요. 사진·그림 파일이 없어서 저작권 걱정이 없고, 어떤 화면 크기에서도 또렷해요
- 정연이는 한 자리(viewBox `0 -20 200 400`)에 겹겹이 그려서 옷을 고르면 그 위에 입혀져요 (옛날 옷 입히기 놀이처럼)
  - 겹 순서: 뒷머리 → 몸 → (속옷) → 신발 → 바지·치마 → 윗옷 → 원피스 → 손 → 얼굴 → 앞머리 → 모자
  - 덮는 모자(밀짚·야구·털·베레·딸기·벙거지)를 쓰면 똥머리·리본처럼 머리 위에 올린 것은 숨겨요
  - 캐릭터 머리띠(마이멜로디·쿠로미·하츄핑, `shape: "charband"` + `motif`)는 색 머리띠 위 정수리에 캐릭터 그림을 얹어요. 덮는 모자가 아니라 머리 모양이 그대로 보여요. 까만 쿠로미 머리띠는 분홍 테두리(color2)라 까만 머리 위에서도 보여요. 그림 높이는 `CHARBAND_Y` (세로로 긴 그림은 조금 위로)
- 옷은 `js/data/items.js`의 값(shape 모양, color 색, pattern 무늬, motif 그림, sleeve 소매, collar 깃)으로 정해요. 새 옷은 한 줄 더 쓰면 돼요
  - 칸마다 옷 15개씩: 원피스 15, 윗옷 15, 바지·치마 15, 신발 15, 모자·머리띠 15 (머리 모양은 17)
- **머리카락은 얼굴(볼)을 가리지 않아요.** 얼굴 테두리는 가운데 (100, 82) · 가로 반지름 47 · 세로 반지름 46
  - 앞머리는 이마만 덮고, 옆은 얼굴 테두리 바깥으로만 내려와요 (`HF.bangs`·`HF.side`·`HF.blunt`)
  - 앞으로 내려온 옆머리(`LOCK`)·땋은 머리·옆으로 묶은 머리는 귀 옆에서 시작해 얼굴 바깥으로 어깨 위에 내려와요. 머리끈도 얼굴 밖에
  - 뿌까 머리: 일자 앞머리 + 양쪽에 땋아서 돌돌 만 동그란 머리 + 빨간 리본 (`braidBun`)
  - 자두 머리: 일자 앞머리 + 턱까지 오는 짧은 단발 + 귀 위에서 옆으로 뻗친 짧은 꽁지 두 개
  - 땋은 마디의 결은 까만 머리에는 밝은 줄, 밝은 머리에는 진한 줄로 그려서 어떤 머리 색에서도 보여요 (`texture`)
- 캐릭터 그림(마이멜로디·쿠로미·하츄핑)은 집에서 쓰려고 단순하게 흉내 낸 그림이에요
  - `images/characters/melody.png`·`kuromi.png`·`hachu.png`(배경 투명)를 넣으면 옷 무늬가 그 그림으로 바뀌어요 (`CHARACTER_IMAGES`, 44×44 상자 안에 비율 유지, 흰 스티커 테두리 `.char-img`). 파일이 없으면 흉내 그림 그대로
  - 지금 세 파일이 들어 있어요 (원본·크기는 `images/characters/README.md`)
  - 그림은 늦게 불러와지므로 무늬 자리(`g.char-motif`)를 표시해 두고 불러온 뒤 그 자리만 바꿔 끼워요 (`Doll.setCharacterImage`)
  - 이 그림 파일은 GitHub에 함께 올라가고 Vercel 사이트에서도 보여요
- 가족(아빠·엄마는 어른 몸, 정우는 정연이와 같은 몸을 키만큼 크게 + 귀 위로 짧게 자른 남자아이 머리·뻗친 머리카락·짙은 눈썹)은 선물 옷을 입은 모습으로만 나와요
- 키를 맞출 때 쓰는 몸 크기는 `Doll.BODY` (아이 `0 -20 200 386`, 어른 `0 -10 200 438`: 발바닥이 그림 아래 끝에 오게 자른 viewBox)
- 옷 칸의 그림은 화면에 붙인 뒤 그림 크기에 꼭 맞게 확대해요 (`Doll.fit`)

## 6. 움직이는 방법 (조작)

- 화면 이동은 주소 뒤 `#`로 나눔 (브라우저 뒤로 가기 버튼이 그대로 동작). 아직 오지 않은 단계 주소로 가면 지금 단계로 돌려보냄
- 넘기기: ◀ ▶ 버튼, 점, 손가락으로 옆으로 밀기(60px 넘게), 키보드 ← →
  - 밀다가 잘못 누를 수 있는 화면은 `nav.noSwipe = true`로 밀기를 끔
  - 넘기자마자 다른 효과음이 나는 화면은 `nav.quiet = true` + 버튼 묶음에 `data-quiet` (딸깍이 겹치지 않게)
- 옷 칸(`#grid`)·사기·돌려주기·사진 버튼은 `data-quiet` (딸깍 대신 뾰로롱·짤랑·찰칵)
- 효과음: 휴대폰은 화면을 누른 순간에만 소리를 낼 수 있어서, 첫 누름 때 소리 장치를 깨움
- 화면이 바뀌면 맨 위로 스크롤하고 초점을 본문으로 옮김 (초점 테두리는 안 보이게). 남아 있는 창·폭죽·떠오르는 글자도 지움
- 이 PC처럼 Windows "애니메이션 효과"가 꺼져 있으면 브라우저가 '움직임 줄이기'로 알려서 움직임이 모두 꺼짐. 움직임을 확인하려면 Windows **설정 → 접근성 → 시각 효과 → 애니메이션 효과**를 켜거나, 검사 도구처럼 '움직임 있음'으로 흉내 냄

## 7. 파일 구성

```
dressroom/
├─ index.html            # 앱 틀 (구름, 위쪽 막대, 본문)
├─ css/style.css         # 디자인 규칙 전부 (색·글씨·부품·화면 크기)
├─ js/app.js             # 효과음, 폭죽·창, 넘기기, 카드 높이 고정, 놀이 상태·기록, 화면 이동과 모든 화면
├─ js/doll.js            # 정연이·옷·머리·모자·가족 SVG 그리기
├─ js/scenes.js          # 나들이 배경 7곳 SVG
├─ js/data/site.js       # 사이트 이름, 아이 이름, 가족 이름
├─ js/data/items.js      # 딸기 규칙(SHOP), 옷 칸, 옷 목록, 처음 옷, 가족 선물, 머리 모양·색
├─ js/data/menus.js      # 나들이 메뉴 카드 7장 ("어디 갈까요?")
├─ fonts/                # 주아 글꼴 + OFL 라이선스
├─ images/characters/    # (선택) 진짜 캐릭터 PNG를 넣는 곳
├─ .gitignore / .gitattributes / .vercelignore
├─ CLAUDE.md             # Claude Code가 이 폴더에서 일할 때 늘 읽는 안내 (이 문서를 가리킴)
├─ docs/디자인규칙.md    # 이 문서
└─ tools/check.mjs       # 자동 검사
```

- 실행: `index.html` 더블클릭 (Edge·Chrome 권장). 빌드 없음
- 배포: GitHub 저장소에 올리면 Vercel이 그대로 배포 (Framework Preset "Other", Build Command 비움, Output Directory 비움). `docs/`·`tools/`·`CLAUDE.md`는 git에만 올리고 Vercel에서는 제외. `tools/work/`(화면 캡처)는 git·Vercel 모두 제외
- 새 화면 만들기: `js/app.js`에 `view…()`를 만들고 `route()`에 주소를 더함. 메뉴 카드는 `js/data/menus.js`에 한 줄 (`theme`은 순서대로 무지개 색, `id`는 `js/scenes.js`의 배경 이름)
- 사진을 쓸 때: 위키미디어 공용 같은 자유 라이선스 사진을 쓰고 출처를 `credits.html`에 적음 (처음 화면에는 출처 링크를 두지 않음). 지금은 사진이 없어서 `credits.html`도 없음

## 8. 자동 검사

`node tools/check.mjs` (Edge 필요, 이 PC 경로 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`)

- 놀이 흐름 (1366×900): 시작 → 이야기 6장(◀ ▶ 안 흔들림) → 백화점(칸마다 15개, 값 10/20) → 입어 보기 → 바구니에 담기(퐁)·빼기 → 담은 칸은 회색 비활성(다시 눌러도 안 담김) → 선물 3개 담기(선물 탭 열십자 리본·광택·반짝이, 아빠 회색 양복) → 🧺 바구니 보기(칸 구분 없이 4개) → 계산해요 → 바구니 보기에서 하나 빼기 → 정말 살까요? → "착한 어린이" 칭찬 + 30개 + 폭죽 → 다시 백화점 → 원피스 3개 담으면 "원피스는 이제 더 담을 수 없어요"(하나 빼면 다시 담음, 다른 칸은 그대로) → 딸기가 모자라요 → 선물은 다시 못 담음 → 계산 → 다 샀어요 → 캐릭터 머리띠 3개(머리띠 + 캐릭터, 머리 모양 그대로) → 내 방(산 옷만) → 윗옷 입으면 원피스 벗음 → 머리 17가지 → 어디 갈까요?(빨주노초파남보) → 나들이(가족 4명, 키 비율 180·160·120·110 ±3%, 발이 같은 땅에, 폭죽) → 사진(찰칵 → 액자 → 또 찍으면 냉장고에 자석) → 어른용 기록
- 옷 목록에서 없어진 옷이 옛 저장 기록(바구니·입은 옷)에 남아 있어도 백화점이 오류 없이 열림 (`G.cart`·`G.outfit`을 불러올 때 정리)
- 6가지 화면 크기에서: 모든 화면 가로 넘침 없음, 위쪽 막대 높이(72/62px), 주아 글꼴, 처음 화면 정연이 그림 크기, 백화점·내 방 거울·옷 칸·끝 버튼이 화면 안에, 바구니 보기 창과 버튼이 화면 안에, 메뉴 카드 줄마다 가운데 정렬, 나들이 사람이 장면 안에, 사진 창(액자·냉장고)이 화면 안에
- 백화점 부품: 담아요 버튼(글자 없이 큰 버튼 + 3가지 반짝 효과), "남은 딸기" 지갑·🔄 없음, 탭 112px + 꾸밈선, 선물 탭 금색 + 다른 효과, "다 골랐어요"
